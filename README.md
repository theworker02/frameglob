# frameglob

Frame validation gates for glob inputs before they hit prod.

**Site:** https://theworker02.github.io/frameglob/

## Install / run

```bash
git clone https://github.com/theworker02/frameglob.git
cd frameglob
node src/cli.js
node --test
```
